# Agent entry point

## Open Corners City on localhost

For a request to open, run or show Corners City locally, read and follow
`board/CORNERS-CITY-LOCALHOST.md`. It is the single startup runbook for Codex
and Claude Code, whether this folder was cloned or extracted from the kit ZIP.
The full builder prompt is not needed just to launch the city.

## Work on the city

Read `CLAUDE.md` completely before changing this repository. Then read
`README.md` and `board/CORNERS-CITY-START.md`. For feature work, also read the
builder prompt at `board/CORNERS-CITY-BUILDER-PROMPT.md`.

This folder is the city workspace root. All student-facing
material is in English. Students decide company structure, roles and purposes.
Keep personal data and grades out. Do not create a parallel task system.
Run `python3 board/check.py` (Windows: `py -3 board/check.py`) after changes,
then verify the actual city feature in a browser. Browser drafts are not shared
company facts. Do not upload, push, publish or send messages without explicit
human authorization. No automatic workflow is included in this package.
