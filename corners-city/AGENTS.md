# Agent entry point

Read `CLAUDE.md` completely before changing this repository. Then read
`README.md`, `board/CORNERS-CITY-START.md`, and the builder prompt at
`board/CORNERS-CITY-BUILDER-PROMPT.md`.

The city workspace root is the workspace. Run the launcher here. All student-facing
material is in English. Students decide company structure, roles and purposes.
Keep personal data and grades out. Do not create a parallel task system.
Run `python3 board/check.py` (Windows: `py -3 board/check.py`) after changes,
then verify the actual city feature in a browser. Browser drafts are not shared
company facts. Do not upload, push, publish or send messages without explicit
human authorization. No automatic workflow is included in this package.
