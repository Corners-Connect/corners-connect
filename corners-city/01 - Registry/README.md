# The registry

One record per session, written **during** the session, not afterwards. A record
written on Friday from memory is a record of what somebody remembers, which is
not the same thing and everybody already knows it.

- `sessions/TEMPLATE.md` — copy it, name it `session-07-2026-09-29.md`.
- `DECISIONS.md` — every decision this company takes, and why.
- `HANDOVER-TEMPLATE.md` — when somebody takes something over from somebody else.

**Where the record stops and the board starts.** The commitments, the hours and
the numbers live in the board — type them there and they are counted. This folder
holds what a machine cannot add up: what was argued, what was decided, and the
best argument that lost.

That last one matters more than it sounds. In December you will want to know
whether the person who lost an argument in October was right.
