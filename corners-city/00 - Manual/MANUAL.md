# The Manual — template

AI for Business · USAC Bilbao · Fall 2026

---

**This is a form, not a document.** It arrives with the questions already asked
and, where it helps, with a suggestion you can accept or throw out. Every
suggestion is marked as such. None of them is a default and none of them is mine
to defend — if you keep one without discussing it, you have wasted the exercise.

**How to use it:** draft it across weeks one and two, ratify it in session five.
Then it lives in `00 - Manual` and gets amended whenever you decide, using the
procedure you write in section 10.

**The only limit:** it has to fit inside the System Prompt. That is the one thing
I check.

## 3 · How we organise

Five rules apply and cannot be voted away. Everything else in this section is
yours to invent.

| Rule | |
|---|---|
| 1 | Every obligation has a name behind it |
| 2 | Nobody without a role |
| 3 | Roles rotate |
| 4 | Every handover is written |
| 5 | The company answers for its own people |
